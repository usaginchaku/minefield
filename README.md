# MINEFIELD

一手ずつ、見抜こう。ブラウザで遊べる、日本語のマインスイーパーです。

▶ **[ブラウザで遊ぶ](https://usaginchaku.github.io/minefield/)**

HTML・CSS・JavaScriptを1つの `index.html` にまとめています。インストール、ビルド、外部ライブラリ、APIキーは不要です。

## 遊び方

数字は周囲8マスにある地雷の数です。地雷のないマスをすべて開けばクリア。最初に開くマスとその周囲には地雷を置きません。

| 操作 | 動作 |
| --- | --- |
| 左クリック・タップ | マスを開く |
| 右クリック | 旗 → 疑問符 → 解除 |
| 盤面上部の旗ボタン | タップ時の操作を「開く／旗」に切り替え |
| 開いた数字をクリック | 周囲の旗の数が数字と一致すると、残りのマスをまとめて開く |
| 矢印キー | 選択マスを移動 |
| Space / Enter | マスを開く・周囲をまとめて開く |
| F | 選択マスの旗 → 疑問符 → 解除 |
| P | 一時停止・再開 |

まとめて開くとき、旗の位置が間違っていると地雷を踏むことがあります。盤面によっては推理だけで決まらず、予想が必要です。

## 機能

- 初級（9×9・地雷10個）、中級（16×16・40個）、上級（30×16・99個）、超上級（40×24・240個）
- カスタム盤面：横8〜50、縦8〜40、最大2,000マス。地雷は全体の35%まで
- 空白マスの連鎖オープン、旗・疑問符、周囲のまとめ開き
- タイマー、一時停止、マスの拡大・縮小、盤面のスクロール
- 安全なマスを開くヒント。使用した回はベストタイムの対象外
- 盤面設定ごとのベストタイム、プレイ数、クリア数の保存
- スマホ・キーボード操作

記録はブラウザの `localStorage` に保存します。サーバーへの送信はありません。保存が利用できない環境でも、その画面を開いている間は遊べます。ローカルHTMLとGitHub Pagesの記録は別々です。

## 手元で遊ぶ

`index.html` を現在のChrome・Edge・Firefox・Safariなどで開くだけです。JavaScriptを有効にしてください。ダウンロードしたHTMLはオフラインでも遊べます。

## GitHub Pagesで公開する

推奨リポジトリ名：`minefield`

1. GitHubで `minefield` リポジトリを作成します。個人の無料プランでGitHub Pagesを使う場合は、公開（Public）にします。
2. アップロード用ZIPを展開し、**中のファイルをリポジトリ直下**にアップロードして `main` ブランチにコミットします。ZIP自体や親フォルダをそのままアップロードせず、リポジトリのトップに `index.html` がある状態にします。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment → Source** で **GitHub Actions** を選びます。このリポジトリでは設定済みです。
5. **Actions → Deploy GitHub Pages** の実行が成功したら、Pages設定画面に表示される公開URLを開きます。手動で再実行する場合は **Run workflow** を使います。

このリポジトリの公開URLは `https://usaginchaku.github.io/minefield/` です。

同梱の `.github/workflows/deploy-pages.yml` が公開を自動化します。アプリのビルドや依存パッケージのインストールは不要です。公開後は `index.html` を更新して `main` にコミットすると反映されます。

## ファイル

```text
index.html   ゲーム本体（CSS・JavaScriptを含む）
README.md    説明と公開手順
.nojekyll    Jekyllによる処理を無効化
.gitignore   OSの一時ファイルなどを除外
.github/workflows/deploy-pages.yml  GitHub Pagesへの自動公開
```

ゲームを変更するときは `index.html` を編集してください。別途ビルドする必要はありません。
